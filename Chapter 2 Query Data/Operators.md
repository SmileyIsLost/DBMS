# Operators in SQL
<img width="2968" height="2168" alt="image" src="https://github.com/user-attachments/assets/76f79181-783c-4c94-aa4c-ad20f364c69c" />

- **Comparison operators**: compare two values (e.g., `=`, `!=`, `>`, `>=`, `<`, `<=`).
- **Range operators**: check if a value is between two bounds (e.g., `BETWEEN value1 AND value2`).
- **Membership operators**: check if a value is in a set (e.g., `IN (...)`, `NOT IN (...)`).
- **Logical operators**: combine or negate conditions (e.g., `AND`, `OR`, `NOT`).
- **Search operators (pattern/text search)**: find matches in text (e.g., `LIKE`, `NOT LIKE`, with wildcards like `%` and `_`).
